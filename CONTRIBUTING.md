# Contributing

Thanks for helping out!

1. Open or pick an issue describing the change.
2. Create a branch from `main`: `git checkout -b feature/short-description`.
3. Keep commits small with clear messages.
4. Make sure CI passes, then open a pull request using the template.
5. At least one teammate reviews before merging.

Never commit secrets. Put local config in `.env` (ignored by git) and document required keys in `.env.example`.

By participating you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
